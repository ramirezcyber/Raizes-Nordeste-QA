Descrição do Projeto
Este repositório contém o protótipo de automação de testes para o Sistema de Gestão Hospitalar e de Serviços de Saúde (SGHSS) da rede VidaPlus. O objetivo principal é validar requisitos de segurança e conformidade com a LGPD através de testes de interface.

Script de Automação
O script principal foi desenvolvido em Python utilizando o framework Selenium. Ele simula uma tentativa de acesso indevido para validar o comportamento do sistema diante de falhas de autenticação.

Funcionalidades:
Auto-Instalador: O script verifica se a biblioteca Selenium está instalada no ambiente e, caso necessário, solicita permissão para realizar o setup automaticamente.

Teste de Login: Automação do fluxo de inserção de credenciais e validação de mensagens de erro.

Como Executar
Certifique-se de ter o Python 3.x instalado.

Execute o arquivo: python teste_seguranca_login.py.

Siga as instruções no terminal para a instalação automática das dependências.
